# MDX with components

This file is `.mdx`, so `{2 ** 10}` evaluates to {2 ** 10} rather than
printing as text.

## Importing components

<Badge label="server-only" /> renders during the response and never reaches the
browser.

<Counter start={0} />

That button is a `clientEntry` component: it hydrates in the browser and keeps
its own state. Both imports are ordinary `import` statements, and this file is
byte-identical between the two demos.
