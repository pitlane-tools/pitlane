# Plain Markdown

This file is `.md`. It has no expressions and no components, so it renders to
an HTML string on either host.

## What that costs

Prebuilt, a `.md` entry reports no headings, which is why this page shows an
empty list under the Vite demo and a full one under the runtime demo.
